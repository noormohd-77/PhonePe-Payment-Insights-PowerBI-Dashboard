# 📊 PhonePe Payment Insights | Power BI Dashboard

## 📌 Project Overview

This project presents an interactive **PhonePe Payment Insights Dashboard** developed using Microsoft Power BI to analyze digital payment transactions, transaction values, customer activity, payment statuses, and user behavior.

The dashboard transforms transaction data into meaningful business insights through interactive visualizations, KPI cards, DAX calculations, data modeling, slicers, and custom tooltips.

The primary objective of this project is to understand payment performance, identify transaction trends, analyze customer segments, and explore service-wise transaction patterns through data visualization.

## 🎯 Project Objectives

- Analyze overall digital payment transaction performance.
- Monitor total transactions and transaction values.
- Evaluate successful payment rates.
- Analyze monthly transaction trends.
- Understand customer activity and age-group contributions.
- Identify the most valuable users.
- Compare weekday and weekend transaction behavior.
- Analyze transaction values across different payment services.
- Provide interactive insights using Power BI features.

## 🛠️ Tools & Technologies Used

- **Microsoft Power BI** – Dashboard development and data visualization.
- **Power Query** – Data preparation and transformation.
- **DAX (Data Analysis Expressions)** – Calculated measures and KPIs.
- **Data Modeling** – Organizing data tables and relationships.
- **Interactive Slicers** – Dynamic filtering and analysis.
- **Custom Tooltips** – Additional contextual information.
- **Data Visualization** – Presenting insights through charts and graphs.

## 📊 Dashboard Overview

The dashboard includes the following key components:

### 1. Key Performance Indicators (KPIs)

The dashboard highlights four major performance indicators:

| KPI | Dashboard Snapshot |
|---|---:|
| Total Transactions | 50K |
| Total Transaction Value | ₹578.08M |
| Total Active Users | 40K |
| Successful Rate | 96.07% |

It also displays month-over-month growth indicators for tracking performance changes.

### 2. Monthly Transaction Analysis

- Monthly transaction volume analysis.
- Monthly transaction value comparison.
- Identification of transaction trends over time.
- Comparison of transaction count and transaction value.

### 3. Age Group Contribution Analysis

Analyzes customer contributions across different age segments:

- Gen X
- Millennials
- Gen Z
- Boomers

This visualization helps understand the distribution of transaction activity across different generations.

### 4. Service-wise Transaction Analysis

Examines transaction value across different PhonePe services, including:

- Loans
- Insurance
- Money Transfer
- Recharge & Bills

This analysis helps identify the services contributing to the overall transaction value.

### 5. Top 5 Users Analysis

- Identifies the top five users based on transaction value.
- Compares individual user contributions.
- Highlights high-value customer activity.

### 6. Weekday vs Weekend Analysis

Compares transaction activity between weekdays and weekends.

**Dashboard Snapshot:**
- Weekday Transactions: 72.3%
- Weekend Transactions: 27.7%

This analysis helps identify differences in payment activity based on the day of the week.

### 7. Payment Status Analysis

The dashboard provides interactive payment-status filtering through:

- Successful
- Failed
- Pending

This allows users to explore payment performance across different transaction statuses.

## 📈 Key Insights

Based on the dashboard snapshot:

1. The dashboard records approximately 50K transactions with a total transaction value of ₹578.08M.
2. The successful transaction rate stands at 96.07%.
3. Total active users are approximately 40K.
4. Loans represent the highest transaction value among the displayed services.
5. Weekdays account for 72.3% of transactions, compared with 27.7% on weekends.
6. Millennials represent the largest displayed age-group contribution at 48.4%.
7. Gen X contributes 33.0%, followed by Gen Z at 11.7% and Boomers at 6.9%.

*Note: These figures represent the dashboard snapshot and may change when interactive filters are applied.*
